# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems.
Report them privately via GitHub's "Report a vulnerability" (Security tab → Advisories)
or by email to security@bluetuple.ai.

I will acknowledge your report within 5 working days and keep you informed about the fix.

## Scope

This repository contains reference code and guides. Review and adapt it before using it
in production. Supported version: the latest commit on `main`.
